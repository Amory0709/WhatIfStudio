# Ethics Policy

1. Explicit consent — one-screen notice before any photo. Modal cannot be dismissed without ticking "I understand".
2. Watermarking — SLB logo burned in, top-right. Outputs are visibly synthetic.
3. No persistence by default — uploaded faces are processed in memory and discarded unless the user opts in.
4. Content moderation — NSFW classifier (opennsfw2) rejects uploads before swap.
5. No celebrity or public-figure content — gallery artworks are curated and clearly fictional.
6. Audit log — anonymized request metadata (no face pixels) kept for 30 days.
